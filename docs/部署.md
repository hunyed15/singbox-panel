# SingBox 面板部署指南

面板:Node.js(Express)+ SQLite + React(antd),SSH 方式管理各机的 sing-box。

## 1. 准备工作

- 一台中心机(建议 3 号),公网可访问(订阅/agent 需要)。
- 生成主密钥:`openssl rand -hex 32`(存进 `APP_SECRET`,务必保密)。
- 目标机器已装 sing-box 或有 SSH 权限(面板可在「服务器」页一键 安装/重启/卸载)。

## 2. 一键安装(中心机)

```bash
sudo bash deploy/install-panel.sh
```

脚本做的事:装 Node ≥20、clone 代码、`npm install` + 构建前端、写 `/etc/singbox-panel/panel.env`(自动生成 APP_SECRET/JWT_SECRET)、注册 systemd 并启动。

首启管理员:`ADMIN_PASS` 留空时随机生成并打印到日志:

```bash
journalctl -u singbox-panel -n 50 | grep bootstrap
```

## 3. HTTPS 反代(强烈建议)

参照 `deploy/nginx.conf.example`(nginx)或 Caddy:

```caddy
panel.example.com {
    reverse_proxy 127.0.0.1:8081
}
```

## 4. 首次建节点步骤

1. 登录面板 → 「服务器」新增机器:
   - **SSH 模式**:填 host/端口/用户/私钥或密码(凭据加密入库,不回显)。
   - **Agent 模式**(预留):机器不可达时使用,后端 V1 未实现。
   - 角色:1/2 选「中转机」(自动生成 Reality 密钥),3-6 选「落地机」(自动生成共享 ss 入站)。
2. 点「检查状态」验证各机 sing-box 状态。
3. 「节点」页新建节点:
   - **VLESS+Reality**:主力,借站域名可在「Reality 域名库」选(内置大厂域名,可增删改)。
   - **出口**:直连(客户端直连本机)/ 中转(经中转机 → 落地机出网)。
   - 端口留空自动分配;VMess/Trojan 等自签 TLS 节点客户端需「允许自签/不安全连接」。
   - 隧道模板:转发到 IPv4/IPv6/域名目标(如 IPv6 互通)。
4. 节点创建/编辑/启停自动触发配置下发(`sing-box check` → 原子替换 → reload,失败自动回滚)。

## 5. 客户端订阅指引

- 「订阅」页复制订阅链接(形如 `https://panel.example.com/sub/<slug>`)。
- **v2rayN / Clash**:UA 自动命中 base64 分享链接列表(也可 `?format=base64`)。
- **sing-box / SFA / SFI**:UA 自动命中 sing-box JSON(`?format=singbox` 强制)。
- SOCKS/HTTP/ShadowTLS/Naive 节点无标准分享链接,请用 sing-box JSON 订阅导入。
- 自签 TLS 节点(vmess/trojan/hysteria2/tuic/naive):客户端需开启「允许不安全连接/允许自签」。
- slug 即密钥:改 slug 旧链接立即失效,防公网扫描。

## 6. 常见问题

- **reload 失败**:面板自动回滚并提示「已回滚」;仍失败则 SSH 上机看 `journalctl -u sing-box -n 50`。
- **sing-box 安装慢/失败**:中心机或目标机 GitHub 不稳时,在 env 里配 `SINGBOX_DOWNLOAD_BASE` 指向 gh-proxy 镜像。
- **Reality 大站握手失败**:域名库换一个借站域名,重建/编辑节点。
- **ss-2022 客户端不支持**:个别客户端降级 `aes-128-gcm`(后端支持项)。

## 7. 验收清单

1. 登录 → 录入 6 台(1/2 relay,3/4/5/6 landing),「检查状态」全部显示。
2. 建 VLESS+Reality(中转→KR3),deploy ok,目标机 `systemctl reload` 生效。
3. 建直连节点 + 隧道节点(转发 IPv6)。
4. 订阅:v2rayN 拉 base64、sing-box 拉 JSON,均含启用节点;停用节点后重新拉取即剔除。
5. 客户端实测连通(含中转链路出口 IP 为落地机 IP)。
6. 删除服务器被节点引用 → 409;删节点后删除成功。
